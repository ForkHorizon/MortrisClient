## 2. Самые рискованные допущения

1. **Синтетика ≈ реальность.** Профиль rich попадает в две цифры отчёта (сырой размер и gzip), но поля выдуманы.
   Если в реальных событиях энтропия сидит в длинных строках (например, сериализованное состояние доски в
   `state_checkpoint`), колонки помогут меньше, а словарь больше. Без 07 Q1 нижняя граница выигрыша неизвестна;
   по устройству эксперимента разумный ожидаемый диапазон −60…−80%.
2. **Словарь не устаревает быстро.** Проверено только «другие установки того же генератора». Новые события в
   обновлении игры словарь не знает. Защита в спецификации: несколько `dict_id`, метрика сервера.
3. **Отчёт игры считал gzip уровня по умолчанию.** Если отчёт считал gzip-1, то калибровка rich занижена на ~15%.
4. **Unity HTTP-стек.** Предположения про `Expect: 100-continue`, отсутствие `Accept-Encoding`, HTTP/1.1 и
   keep-alive у `System.Net.Http.HttpClient` под Mono/IL2CPP на Android не проверены.
5. **Батарея.** Влияние размера тела на батарею почти наверняка меньше, чем влияние числа пробуждений радио
   [источник: Android]. Цифр по батарее в отчёте нет, только направление.

## 3. Где слабые места методики

- Protobuf закодирован вручную по wire-формату, без `protoc`. Проверка: сгенерировать `.proto` из docstring и
  сравнить `protoc --decode_raw`.
- Сжатие в Python через C-библиотеки, но уровни и параметры могут отличаться от того, что будет в Android
  (zstd-jni, версия библиотеки). Размеры от версии zstd меняются на единицы процентов.
- `run_http.py` моделирует TCP грубо (1 ACK на направление, без потерь, без TCP Fast Open, IPv4).
- Fuzz декодера без покрытия и без бомб. Продуктовый декодер нужно гонять libFuzzer/AFL/Jazzer с корпусом из
  `results/example_payload.bin` и лимитами §9.
- CPU мерился на десктопе в одном процессе, без учёта холодного кэша и троттлинга телефона.

## 4. Быстрая проверка за 5 минут

```bash
cd 04-experiments && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python test_roundtrip.py          # C2
.venv/bin/python run_conservative.py        # C4, C5, часть C6
.venv/bin/python run_stateful.py base       # C7, C8
```

Если любая цифра в `03-ablation.md` не совпадает с выводом скриптов более чем на ±0,5 Б/событие (кроме CPU), это
ошибка отчёта.
