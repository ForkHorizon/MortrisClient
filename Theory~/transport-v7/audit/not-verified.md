# Не проверено / ограничения

- Проверки на физических телефонах, реальная производительность, батарея, фоновые ограничения OEM и внезапная физическая потеря питания.
- Целевые Unity Android handlers на разных Unity/Mono/IL2CPP версиях для меж-origin HTTP redirects. Повтор тела подтверждён только стандартным .NET 10 handler.
- iOS, WebGL, Standalone и ARMv7 runtime на физическом устройстве.
- Полная детерминированная пересборка трёх zstd библиотек из исходного tarball; проверены их SHA256 по `SHA256SUMS`, Gradle AAR parity.
- Исчерпывающие fault injection сценарии: сетевые обрывы на каждой границе записи, сервер 5xx/429, часы устройства, переполнение/долговременный рост очереди и filesystem exhaustion.
- Указанные в задании exporter integration тесты на origin/main не запускались: верификация ограничена V7 worktree, а существующий основной checkout запрещено менять.
- Production и внешние аналитические SDK не использовались. Puzzle replay не опубликован; в отчёте только синтетический пример и агрегаты.
