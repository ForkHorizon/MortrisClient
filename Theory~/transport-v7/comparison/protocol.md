то лишь для синтетической нагрузки.

## 3. Заморозка конфигурации V7

Основная конфигурация (не меняется после просмотра test): универсальный каталог
проекта → колонки → числовые/строковые модели (flags из `11-final-conclusions.md`) →
zstd level 1 со словарём dict32 (32 КиБ), обученным только на train; sequence
identity вместо event UUID. Для synthetic корпусов catalog и словарь обучаются
только на train-seeds. Любые другие варианты (dict16, другие уровни, cross-column)
— *exploratory* и в claims не попадают как победа.

## 4. Матрица нагрузок

Трек A (одна семантика) / трек B (архитектура продукта) — как в задании.

| Ось | Значения |
|---|---|
| Размер пачки | 1, 10, 100, 500 |
| Частота | 1, 10, 60 событий/с + ограниченный burst (только как расчёт, без реальной сети) |
| Данные | Puzzle raw; Puzzle clean (hash_wave_clean, all_clean); synthetic: низкая/высокая энтропия, UUID, Unicode/длинные строки, schema drift, короткие сессии |
| Режим | cold (setup: catalog+dictionary) / warm steady state |
| Повторы | ≥5 независимых запусков для каждого *измеряемого по времени* сценария; размеры детерминированы — повторы подтверждают байтовое совпадение, а не дают доверительный интервал |

Warmup для таймингов: 200 итераций, затем ≥1000 измеряемых; исключение — запуск
с ошибкой или выбросом при зафиксированной внешней нагрузке (журнал `load.txt`).

## 5. Способы измерения и ограничения

- **Body bytes (метрика 1)**: фактический вывод C# M7 encoder (`Frames.csproj`), V1 — восстановленный
  JSON + gzip level 1 из DB jsonb. Ограничение: не оригинальные HTTP-тела.
- **HTTP/TLS/полный обмен (метрики 2, 3)**: **не измеряются** — нет сервера приёма,
  аккаунтов и устройства. Помечаются NOT_MEASURED; любые числа — MODELED с предпосылками.
- **CPU/GC**: только хост .NET (ранее собранные результаты) и сохранённые Unity-эмуляторные
  результаты; телефон — NOT_MEASURED. GC — `GC.GetAllocatedBytesForCurrentThread` с положительным контролем
  (в Unity это stub, поэтому Unity-значения берутся из ProfilerRecorder отчёта 06).
- **Конкуренты**: официальные SDK не установлены и не запускались. Всё о конкурентах —
  DOCUMENTED_ONLY (URL и дата в `inventory.md`). Самодельный REST-клиент не выдаётся за SDK;
  допускается только *MODELED нижняя оценка* тела по документированной схеме, явно названная так.

## 6. Общие параметры окружения

Одинаковая очистка либо её отсутствие у всех сравниваемых вариантов; одинаковые события и поля;
необязательные функции SDK (автосессии, авто-события) в сравнении не участвуют, потому что
реальные SDK не запускались. Порядок запусков по времени — чередование блоков, где применимо.
