2. **Uncertainty policy**: define practical effect thresholds and a justified replication rule per objective; decide whether a formal test is wanted. Today CPU verdicts are descriptive and need n >= 3.

4. **Unify `explore` into the store** (import study measurements) so a single store holds all evidence; add actions G (design candidate via a domain candidate factory) and H (structured conclusion).
5. **Run children from the evaluator lock** (execution isolation), which requires resolving data paths independent of the package location; generalise "reference" as a campaign parameter instead of a Problem subclass.
6. **Literal mission continuity** across route segments (rotate manifests inside one mission) if the shared-store/briefing design proves insufficient.
7. A sealed, installation/session-disjoint confirmation cohort. Without it no result may be called a discovery.
8. A second research domain on the contract (bin-packing or compression) to prove generality; today only legacy paths run it.
9. 30-minute assessment interval and a multi-round slot on real controllers in the v2 supervisor; provider-interruption and quota drills live.
