
## 3b. Выводы по таблицам

* **Размер пачки (D, сервер без лимитов, 3000 событий)**: байт/событие вверх — V8 56.6 / 28.9 / 18.2 / 15.8 при пачках 10 / 30 / 100 / 200; V7 81.8 / 37.5 / 21.5 / 22.6; V1 185 / 111 / 84 / 84. Выигрыш V8 над V1 растёт с размером пачки (3.3× → 5.3×). При пачке 10 клиент принимает на 14% меньше событий (буфер 1024 не успевает освобождаться: каждая мини-выгрузка занимает рабочий поток).
* **Частота (D, таймеры SDK по умолчанию)**: V8 вверх 26.7 / 21.7 / 21.2 / 20.8 байт/событие при 1 / 10 / 30 / 100 событий/с; с TLS и ответами 116 / 35 / 27 / 24 — на 1 событие/с рукопожатия TLS доминируют (4 соединения и 9 запросов на 302 события; тела пакетов занимают 6.5 КБ из 35 КБ). V1 вверх ≈ 94–110, GameAnalytics 235 → 80 (дороже на низкой частоте), Amplitude Kotlin ≈ 1330–1380 при любой частоте. За 5 минут при 1 событии/с V8 доставил все 302 события, V1 только 101 (ждёт таймер 120 с и порог 200).
* **Всплески (E/E2)**: Mortris принимает ≈2.1–2.7 тыс. событий из любого всплеска ≥6000 за кадр (остальное — `HandoffFull`), вес стабилен (V8 ≈ 20 байт/событие); Amplitude Kotlin, HyperKit и Mixpanel принимают и доставляют все 20 000 (Mixpanel — 501 запрос, 1968 байт/событие); GameAnalytics принимает все, но доставляет 4.0 тыс. из 20 тыс. и 4.7 тыс. из 100 тыс. (внутренний предел), Amplitude 2.40.1 — 1080 из 20 000. Макс. время работы в кадре при 20 000 `Track()` подряд на телефоне: Mortris 185 мс, Amplitude Kotlin 590, Mixpanel 3521, Amplitude 2.40.1 2978, GameAnalytics 407.
* **Сервер (F)**: стоимость сервера на событие почти не зависит от транспорта (V1 ≈165–175 мкс, V7 ≈147, V8 ≈156–167 мкс CPU сервера + ≈105–130 мкс PostgreSQL): доминирует запись в БД, а не разбор. Преимущество V8 — в трафике и в телефоне, а не в CPU сервера. 50/100/190 параллельных установок: ошибок нет (после исправления дедлока), память сервера ≈150 МБ, PostgreSQL до 1.1 ГБ.
* **GC/память (A3)**: у Mortris Mono GC0 ≈6 за 3000 событий против 1 у всех остальных (их аллокации живут в Java: Amplitude Kotlin 72 КБ/событие, Facebook 64, GameAnalytics 29, Mixpanel 23, Amplitude 16; у Mortris Java-часть 4–5 КБ/событие). Пик PSS: база 265 МБ; Mortris +20, GameAnalytics +114, Amplitude 2.40.1 +107, Facebook +71, Mixpanel +43, Firebase +39.
